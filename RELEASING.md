## Installation Instructions

### For Users (Quick Start)

1. **Download the APK:**
   - Go to [GitHub Releases](https://github.com/barjuos/rafik/releases)
   - Click on the latest `app-release.apk` file
   - Save it to your device

2. **Install on Android Device:**
   
   **For Android 8.0+ (Oreo and above):**
   ```
   Settings → Security → Unknown Sources → Enable
   → Install the APK
   ```

   **For Android 7.0 and below:**
   - Go to Settings
   - Enable "Install unknown apps" for your browser or file manager
   - Open the downloaded APK and install

3. **First Launch:**
   - The app will verify the license (takes a few seconds)
   - Allow necessary permissions if prompted

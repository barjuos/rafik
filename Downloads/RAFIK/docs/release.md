## Installation Guide

### Prerequisites
- Android 7.0 (API 24) or higher
- At least 50MB free storage space

### Step-by-Step Installation

1. **Download the APK** from [GitHub Releases](https://github.com/barjuos/rafik/releases)

2. **Enable Unknown Sources** (if installing manually):
   - Go to **Settings** → **Apps** → **Special Access** → **Install unknown apps**
   - Select your browser or file manager
   - Toggle **"Allow from this source"** ON

3. **Install the App**:
   - Open the downloaded APK file
   - Tap **"Install"**
   - Wait for installation to complete

4. **Open Rafiq**:
   - Find the Rafiq icon on your home screen or app drawer
   - Tap to launch the app

### Uninstalling
- Go to **Settings** → **Apps** → **Rafiq** → **Uninstall**

## 🔧 Troubleshooting

### "App can't be installed" Error
- Ensure you have at least 50MB of free storage
- Check if another version is already installed
- Try uninstalling the old version first

### "App blocked from installing" Warning
- This may appear if you've set up app verification in Play Protect
- Go to **Settings** → **Security** → **Unknown Sources** and enable installation

### Installation Fails on Older Android Versions
- Rafiq requires Android 7.0 or higher
- Check your device's Android version: **Settings** → **About Phone** → **Android Version**

STEP 1: Generate Your Keystore (5 minutes)
--------------------------------------------------------------------------------
Open PowerShell and run one of these commands in the android/ folder:

   cd C:\Users\ibrah\Downloads\RAFIK\android
   
   # Method 1 - PowerShell script (recommended):
   .\create-kestore.ps1
   
   # OR double-click create-keystore.bat if running from file explorer

Follow the prompts to enter a strong password. This creates:
  - rafik-release.keystore (YOUR PRIVATE KEY - keep secret!)
  - keystore.properties (fill in your password)


STEP 2: Build Your Secure Release APK
--------------------------------------------------------------------------------
After creating the keystore, build the release version:

   .\gradlew.bat assembleRelease

The secure APK will be at:
  android/app/build/outputs/apk/release/app-release.apk

Note: This step WILL FAIL without the keystore - that's expected!


STEP 3: Upload to GitHub Releases
--------------------------------------------------------------------------------
1. Download app-release.apk from build folder
2. Go to: https://github.com/barjuos/rafik/releases/new
3. Create release with tag (e.g., v1.0.0)
4. Upload the APK file
5. Share the download link with users
